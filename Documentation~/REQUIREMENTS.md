# EasyToon for URP — 要件定義

高品質 NPR（Toon）キャラクターシェーダー。EasyPBR（`com.origuma.easypbr-urp`）が「PBR 基調＋なんちゃって Toon」なのに対し、本パッケージは **Toon を本命**とする。

- ターゲット: **PC 環境 / Unity 6 (6000.3+) / URP 17.3+ / Render Graph 有効 / Forward+**
- 用途: 人気ゲーム・3D ライブ品質のキャラクター描画（クローズアップ〜多人数同時描画）
- 設計哲学: **BaseMap 一枚で成立し、質感はベイクで積み増す**（EasyPBR と同じ思想）

## 設計の柱となる技術

現行のハイエンド NPR キャラクター表現で広く使われている技術を土台に、以下を採用する。

| 分類 | 取り入れる技術 |
| :--- | :--- |
| **陰・影** | Ramp テクスチャによる陰の色設計、ベイク AO による影しきい値の局所オフセット（常影・影になりやすさ）、陰色の彩度保持（ただ暗い影にしない）、Face SDF によるライト追従の顔影、キャラ専用セルフシャドウマップ（キャラ限定深度描画＝超クリーンな自己影） |
| **ハイライト・エッジ** | スクリーンスペース深度リムライト（ピクセル幅一定・ライト方向オフセット）、フレネルリム、エッジの立ったセルスペキュラ、天使の輪（異方性バンドのトゥーン化）、金属の MatCap 表現、部位別アウトラインカラー、頂点カラー×距離正規化アウトライン |
| **顔・髪** | 眉・まつ毛の前髪透過（ステンシル）、髪→顔の落ち影 |
| **演出・運用** | HDR エミッション（ネオン・発光演出）、キャラ単位の一括制御コンポーネント、キャラ専用ライト方向オーバーライド、ライブステージ運用（白飛び防止・リムでシルエット確保・暗所可読性） |

## 機能要件

### R1. Toon シェーディングコア（最重要）

- **2 段影（1影・2影）**: しきい値・ぼかし幅・色を各段独立に設定。陰色は乗算色＋**色相シフト/彩度制御**（ただ暗い影を禁止。EasyPBR の Shadow Hue Shift を継承）
- **Ramp テクスチャモード**: 数値制御（2段影）と Ramp テクスチャ（色設計をランプに委ねる方式）を uniform 分岐で切替
- **影しきい値オフセットマップ**: ベイク AO（`_OcclusionMap`）を「影になりやすさ」として陰しきい値へ局所オフセット（AO を「影の付きやすさ」に流用する方式）。0=常影 / 0.5=ニュートラル / 1=常明
- **Shade Normal**: ベイク平滑化法線（`_ShadeNormalMap`）で陰の輪郭を一本の綺麗な曲線に（EasyPBR 資産を再利用）
- **落ち影と陰の分離**: Cast Shadow（シャドウマップ）と NdotL 陰を分離合成し、落ち影専用色を持つ
- **間接光**: SH Flatten / Intensity / Tint（EasyPBR の Indirect Light 整形を継承）

### R2. 顔

- **Face SDF 影**: ベイク 4ch SDF（`_FaceSDFMap`、EasyPBR Baker 再利用）でライト方向に滑らかに追従する顔影。左右非対称対応
- **前髪透過（眉・目の透け）**: ステンシルベース。眉・まつ毛・アイラインが前髪越しに指定アルファで透ける（NPR キャラの定番手法）。マテリアル種別（Face / Brow / Hair / Eye）ごとのステンシル運用をプリセット化
- **髪の落ち影**: キャラ専用シャドウ（R4）による自然な髪→顔の落ち影＋顔専用バイアス。スクリーンスペース方式（R9）と併用可
- **頬・チーク**: BaseMap に対する乗算/加算レイヤ（マスク＋強度）※優先度低

### R3. スペキュラ・髪・目

- **セルスペキュラ**: しきい値で縁を切った様式的ハイライト（Specular AA 込み）。Blinn-Phong ベースをステップ化
- **天使の輪（Angel Ring）**: ヘアフローマップ（`_HairFlowMap`、Baker 再利用）駆動の異方性バンドをトゥーン化。ビュー/ライト追従の配合比を制御可
- **金属 MatCap**: ビュー空間 MatCap による金属表現（MatCap 乗算/加算、ライト連動回転は EasyPBR 資産流用）
- **瞳**: ハイライト MatCap、HDR エミッション、前髪透過（ステンシル）対応

### R4. キャラ専用セルフシャドウ

- RendererFeature がキャラ（登録された Renderer 群）だけをライト方向の専用深度マップへ描画し、シェーダーがそれをサンプル
- URP シャドウマップ非依存 → シーン影解像度に左右されない**超クリーンな自己影**
- フォールバック: Feature 未使用時は URP メインライト影（EasyPBR の HQ シャドウライブラリ `Shadow_HQ_URP.hlsl` を流用した PCF）で動作
- PC 前提: 解像度 1K〜4K、複数キャラはアトラス割当

### R5. リムライト

- **スクリーンスペース深度リム**: 深度テクスチャをライト方向へ数ピクセルオフセットしてサンプルし、深度差でリムを生成。**画面上の幅がピクセル一定**（距離・FOV 非依存）。色 HDR 対応
- **フレネルリム（従来式）**: 深度リムと併用/フォールバック。ライト方向マスク（受光側/陰側）付き
- **バックライトリム**: ライブ演出用。ライトと独立した方向指定のシルエットリム

### R6. アウトライン

- 背面法線拡張方式。**頂点カラー R=太さ / G=Zオフセット** による部位制御
- カメラ距離・FOV 正規化（近接で太らない、遠方で消えない、スクリーン幅上限クランプ）
- 色: 固定色×BaseMap ブレンド（部位ごとに馴染む線。EasyPBR の Albedo Blend を継承）
- 独自 LightMode ＋ RendererFeature 方式（ForwardLit のバッチングを阻害しない。EasyPBR の設計を踏襲）
- 法線ソース: 通常法線 / ShadeNormal / UV 格納スムーズ法線(将来) を選択可

### R7. エミッション・演出（ライブ運用）

- HDR Emission（Bloom 誘発を意図した強度設計。ネオン・発光演出）
- **Black Out / Dissolve**: EasyPBR 資産を流用
- **Light Conditioning / Anti-Blowout / Fill Light**: EasyPBR の運用機能を継承（原色照明・多灯・暗所での可読性維持）
- **キャラ単位一括制御コンポーネント**（`ToonLiveDirector` 相当）: ライト方向オーバーライド（キャラ専用仮想ライト）、Black Out、リム強度等を Timeline から駆動。SRP Batcher 維持（Play=マテリアルインスタンス / Edit=MPB プレビュー）

### R8. ベイク（既存資産の再利用）

EasyShaderCore（`com.origuma.easyshader-core`）の Baker 群（AO / Cavity / Curvature / Shade Normal / SSS / Hair Flow / Face SDF）を**そのまま再利用**する。

- 新シェーダーのマップ用プロパティ名を Baker と**同名**にする（`_OcclusionMap` / `_ShadeNormalMap` / `_HairFlowMap` / `_FaceSDFMap` 等）→ Baker の自動アサインがそのまま機能
- Baker 群は EasyShaderCore で `public`（名前空間 `Origuma.EasyShaderCore.Editor`）。Editor asmdef 参照だけで呼べる
- Baker の呼び出し面（`Bake(root, material, Settings)`）は互換維持

### R9. 表現拡張

- **髪→顔のスクリーンスペース落ち影**: 顔ピクセルから「ライト方向のスクリーン投影向き」へ数 px 先の深度を参照し、手前に薄い遮蔽（前髪）があれば落ち影にする。深度差の窓（min/max）で「近くの薄いもの」だけを拾い、キャラ影（R4）より精細な**画面解像度そのままの前髪影**をクローズアップで出す。深度リム（R5）とインフラ共有。既定 OFF
- **ストッキング/シアー生地**: 肌ベース（BaseMap）の上に、視角依存の不透明度を持つ布レイヤを手続き的に重ねる。正面（NdotV 大）は肌が透け、シルエット近く（NdotV 小）は布が密に見える＝糸密度の視角変化を近似。布色・密度・すそ光沢（シアーシーン）を制御、適用範囲は R マスク。既定 OFF

## 非機能要件

- **SRP Batcher**: 全プロパティ単一 CBUFFER。キーワードは「動的分岐で損する処理」のみ（Alpha Clip / キャラシャドウ有無 等）。それ以外は uniform 動的分岐（EasyPBR の設計哲学を踏襲。⚡マーク可視化も同様）
- **既定値で成立**: BaseMap 一枚＋既定値で破綻しない見た目。ベイク・各機能は既定 OFF または未ベイク時計算スキップ
- **パス構成**: ForwardLit / ShadowCaster / DepthOnly / DepthNormals / Outline（独自 LightMode）
- **Render Graph 対応**: RendererFeature は Render Graph API（`RecordRenderGraph`）で実装
- **ライセンス**: MIT。新規 UPM パッケージ `com.origuma.easytoon-urp`、依存 `com.origuma.easyshader-core`（Common HLSL・Baker・GUI 部品の共有）

## スコープ外（初期リリース）

- モバイル最適化 / Built-in RP / HDRP
- 服のシワ法線自動生成、フェイシャル連動（表情で影を消す等）
- スクリーンスペースアウトライン（ポスト方式）
- VRM ランタイムロード時の自動マテリアル変換
